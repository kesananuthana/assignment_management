# LLM prompt history and AI-use disclosure

## Prompt history
The project was implemented from the supplied assignment workflow specification. The key instruction was to generate master data first, then dependent transactions with valid IDs, apply documented business rules, retain event history, inject four labelled anomaly classes, validate the dataset, and export reproducible CSV/JSON/SQL documentation.

## Where AI accelerated work
- Translated the business brief into entity relationships, field definitions, validation rules, and a reproducible generator structure.
- Drafted the initial generator, schema, documentation, and test checklist.

## What the developer must personally review
- Run the generator locally at starter and full scale.
- Review all business rules, especially due-time timezone handling, late penalty policy, resubmission eligibility, grade reconciliation, and appeal audit history.
- Inspect generated samples and validation output.
- Apply the PostgreSQL schema to a local database and verify foreign keys.
- Commit meaningful changes and document any edits made after AI assistance.
